---

- 动态页新增 Ech0 数据源（`/api/ech0.json` 同源代理，运行时近实时）：Markdown 与内嵌 HTML 渲染、图片画廊、标签点击筛选、搜索与年份归档全量适配，侧边栏「最新动态」同步切换
- 说说卡片支持 Ech0 扩展卡片渲染：音乐（Meting 解析迷你播放卡，失败降级链接卡）、推文（widgets.js 嵌入，6 秒超时降级）、视频（B 站/YouTube 内嵌）、网页与 GitHub 链接卡；位置信息映射到卡片 meta 行
- 点赞双轨制：Ech0 数据源走原生点赞，计数与 Ech0 站内互通；其他数据源走自部署 star-vote，localStorage 防重复统一生效
- 友链页面本站信息新增站点截图与 RSS 地址字段（可复制），友链申请从邮箱/评论区改为页面表单提交
- 项目展示页文档按当前魔改现状重写，新增 Ech0 接入技术博文
- 默认主题色调整为松江色（色相 102），社交图标新增 meteor-icons 图标集，同步上游标签换行样式与项目卡片打磨
